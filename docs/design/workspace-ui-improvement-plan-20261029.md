| --- | --- | --- | --- |

## 实施回执

本轮四批范围已完成。只改 Web 展示与工作区聚合，未修改 Java、数据库契约、源写回或公司部署。

- 首页：移除问候、口号、重复引导；输入缩短，快捷提问只填草稿。数据范围保留单一入口。未新增无真实对象支撑的展示卡片。
- 画布：任务原文折叠；无建议不显示零计数；单对象不展示选择列表与分页；画布按可用视口等比适配。银行页由两个查询入口归为一个正式对象，多屏页保留三个入口。
- 引用：查询过滤条件按字段和值归一，包含冻结集合。不同查询只有在现有对象读取接口返回同一个对象、产品版本及数据集合时才合并，不按标题猜测。复用对象读取缓存；失败查询仍能进入原读取错误界面。
- 建议：按正式目标及版本默认展示每个目标的最新建议，旧执行记录保留在历史分组。实测 12 条执行提案呈现为 4 条最新建议与 8 条历史建议，不宣称等于 4 个当前业务问题。列表含大屏、轮次、状态与改动摘要；状态仍取自后端。
- 详情：移除选区同步说明、重复标题及无值字段；时间与记录属性后置，组件统计折叠。核心指标直接通过既有关系及对象详情读回单位、口径和含义，不根据显示文案推断绑定。
- 提案：首先展示真实状态、当前环境可用性和修改前后，长判断与信息缺口置于依据；原准备、确认、核查 API 和授权保持。
- 图形：移除 123、65% 固定数字，以缺数占位代替；保留结构与图形类型示意，不宣称有真实业务值或最终地图渲染。
- 外围：历史页统一为“分析记录”，领域标签后置为辅助读取信息；折叠导航只显示最近四条及当前会话。设置面板缩小、移除重复主题说明，关闭按钮可访问名称中文化。数据页入口明确只填写问题，不冒充直接对象浏览。

## 第三轮：剩余 UI 收尾（2026-10-29—30）

- 画布：目录与分析页共用放大弹层，可切换适应宽度、100%、150%，大图在弹层内滚动。补区域列表，避免窄屏只能点击微小图形；键盘可展开列表并选中核心区。关闭弹层恢复到放大按钮，关闭目录预览恢复到大屏条目。
- 图形：普通模块改为中性表面；蓝色趋势／排行、赭色占比、青色空间构图，深色有对应颜色；陶土橙继续承担选区和动作。主视觉去掉重复长说明，保留源标题、指标、规格标识及真正的诊断，源描述通过提示和原详情读取。
- 记录：保留完整问题参与搜索，不再因 28 字截断丢失尾部对象；同题记录显示时间和短记录标识，折叠导航名称带时间，删除目标增大。没有生成虚构业务摘要，也未新增持久化重命名契约。
- 后台：定义、发布和变更页删除重复引导；新建表单保留必填、格式、兼容性和影响范围说明，移除字段的自我复述。补齐正式类型的中文标签，类型检查要求覆盖当前枚举；未改变提交值或治理流程。
- 响应式与语义：后台窄屏导航换行，版本选择和搜索适应容器；导航仅最具体路径高亮。补搜索／版本可访问名称与筛选选中态；后台保留单个 main，加载状态不再嵌套 main。
