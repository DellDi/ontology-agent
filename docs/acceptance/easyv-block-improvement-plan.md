## 产品边界

- 首期处理已有原型中的普通内容块，保持块外框和业务目标，只改所选块。地图主视觉、核心指标区、动态面板和整屏改造不纳入首期。
- 用户说“这块表达清楚吗？帮我改好”，不需要输入阶段码、工具名或内部标识。
- 判断覆盖主题与指标、指标与图形、整体主次与重复、空间可读性。业务判断展示依据与信息缺口，不包装为已校准的质量分。
- 先复用块内已绑定指标，调整图形与槽位；新增或替换指标必须取得 EasyV 当前可用候选及数据绑定，不能凭名称生成或伪造接通状态。
- 诊断确认为标题/用途与内容不符时，可只修改这两项文案；保留所有组件、绑定、图形与几何位置，不为制造变化而重新布局。文案变化同样先展示差异，再准备、确认和核对。
- 沿用现有只读画布、对象详情和比较呈现，不新增拖拽编辑器、通用工作流或动作配置平台。结构示意不冒充真实效果。
