## 本批交付

| 用户场景 | 结果与边界 |
|---|---|
| “每月创建了多少应用？打开某个月看看。” | 根对象实例 count 支持日、周、月、季度、年分桶；保留原筛选并与所选时间段求交。不把 SUM、比率、去重其他对象的数值解释成根对象数量。 |
| “这期和上期相比，分别有哪些应用？” | 当前期与对比期使用各自日期范围和显示单元格；比较表格按实际预览行数偏移，对比期单独有结果时也可查看。 |
| “这个应用有哪些操作记录？” | 应用关系提供操作记录时间线，按日志时间倒序、主键稳定分页，中文类型和日志结果展示；点击读取详情与用户原话。名称、时间属性、来源说明来自本体，前端无领域词典。 |
| “关联记录超过一页时怎么继续看？” | 通用关系列表每页 20 条，上一页/下一页；翻页记录实际数据版本，更新导致不同版本时拒绝混合展示。分页上限保留明确提示。 |

时间线是操作日志，不是大屏编辑修订历史。日志成功不能证明修改生效、最终采用或用户满意；操作日志的记录时间不等于请求发起时间或编辑发生时间。
