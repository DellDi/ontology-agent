## 已确认的源业务

只读观察现有 SaaS 测试页面的银行驾驶舱，普通「全省总览指标」模块之外，还有独立的「总资产规模／净利润／资本充足率」核心区。对应源实现：

- `CoreMetricsSectionInjector` 将模板 `type="core-metrics"` 容器实例化为独立 Block，标记 `metric_role="core"`，一项指标一个块；五项采用 `2.4/12` 等分跨度。
- `CoreAreaLayouter` 输出同名核心 Block，JSON `metricRole="core"`，单个组件铺满，保留 `boundMetricIds/boundMetrics`；`schemeId/blockTypeId` 为空是正式契约。
- 源前端 `prototype-layout-parser.ts` 让 `fillLayout=1` 的主视觉覆盖其自身和同栏核心区的并集，核心区叠放在上层；`fillScreen` 不参与原型布局。

观察截图位于本机忽略目录 `.codex-runtime/core-metrics-20261027/source-test.png`。仅观察，没有编辑或生成源应用。
